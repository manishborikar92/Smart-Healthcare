# web

This workspace contains the frontend application for Smart Healthcare AI, rewritten in Next.js 16 with the App Router.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.

## Tech Stack
- React 19 / Next.js 16
- Tailwind CSS v4
- Hugging Face Gradio Client
- Framer Motion

This frontend communicates directly with the external ResNet-50 v2 Hugging Face space without requiring a true Node.js backend layer.
